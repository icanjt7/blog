## Figma AI 모션 그래픽, 어떤 변화가 생겼나?

2026년 6월 24일, Figma가 연례 Config 컨퍼런스에서 AI 모션 그래픽 및 셰이더 도구 출시를 공식 발표했습니다.  
이 업데이트는 디자이너와 개발자들이 반복적인 작업을 줄이고, 아이디어를 빠르게 시각화할 수 있도록 지원하는 것이 핵심입니다.

## Figma, 어떤 회사인가?

Figma는 실시간 협업 디자인 플랫폼을 제공하는 기업으로, 웹 기반 UI/UX 디자인 도구 시장에서 대표적인 위치를 점하고 있습니다.

## 사용자에게 달라지는 주요 포인트

| 기준         | 변화 내용                                                                               |
|--------------|-----------------------------------------------------------------------------------------|
| 적용 대상    | Figma 제품 사용자, 디자이너, 개발자, 팀 단위 프로젝트                                 |
| 새 기능      | AI로 자동 생성되는 모션 그래픽, 셰이더(Shader) 효과 편집 도구 추가                     |
| 공식 발표    | 2026-06-24, Config 컨퍼런스에서 발표                                                   |
| 실제 영향    | 반복 작업 자동화, 디자인 시각화 속도 향상, 코드 연결 기능 강화                         |
| 접근 조건    | Figma 공식 웹·앱 서비스에서 바로 사용 가능, 별도 추가 요금 안내는 발표에 포함되지 않음  |

## 체크리스트: 실제 사용자 입장

- 자동 모션 그래픽 생성으로 작업 시간 단축
- 셰이더 효과를 코드 연결 없이 시각적으로 조정 가능
- 팀 단위 협업에서 디자인-프로그래밍 간 경계가 줄어듦
- 출시 즉시 공식 서비스에서 사용 가능
- 가격·구독 변동 여부는 The Verge 발표 기사 기준 별도 공지 없음
