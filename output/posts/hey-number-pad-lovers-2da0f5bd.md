Hey number pad lovers,  
숫자 키패드를 포기할 수 없는 분들에게 새로운 선택지가 등장했습니다. Epomaker RT98은 오랜만에 숫자 키패드 사용자들의 요구를 한 번에 반영한 기계식 키보드로, 2026년 7월 4일 공식 공개 소식이 전해졌습니다.

## Epomaker RT98, 무엇이 다른가

Epomaker는 2016년 설립된 중국의 기계식 키보드 전문 브랜드입니다. 이번 RT98 모델은 일체형 숫자 키패드, CRT 모니터를 연상시키는 소형 화면, 그리고 VIA(오픈소스 키맵핑 툴) 호환성이라는 세 가지 특징으로 주목받고 있습니다.

특히 숫자 키패드를 키보드 본체에 통합해, 별도 모듈 없이 자연스러운 입력이 가능합니다. 기존의 텐키리스(TKL)나 75% 배열 키보드에서는 숫자 입력이 잦은 사용자들에게 불편함이 컸지만, RT98은 이 부분을 개선했습니다.

CRT 스타일의 화면은 단순 장식이 아니라, 현재 입력 상태나 키맵핑 설정을 실시간으로 보여주는 용도입니다. 여러 작업 환경을 오가거나 커스텀 키맵이 많은 사용자에게 실용적입니다.

VIA 호환성 역시 큰 장점입니다. 키 배치 변경, 매크로 설정을 자유롭게 할 수 있어 엑셀, 회계, 게임 등에서 단축키를 자주 쓰는 사용자에게 효율적입니다.

## 주요 특징 비교표

| 항목                 | Epomaker RT98                        | 기존 기계식 키보드           |
|--------------------|--------------------------------------|----------------------------|
| 숫자 키패드        | 일체형(분리 필요 없음)                | 주로 미포함(TKL/75% 등)    |
| 디스플레이         | CRT 스타일, 입력·설정 정보 실시간 표시 | 없음                       |
| 키맵핑(VIA) 지원   | 공식 지원                             | 제한적 또는 미지원          |
| 디자인            | 레트로 감성 + 실용성                  | 클래식·모던 다양            |
| 타건감            | 묵직한 반발력, 부드러운 키감           | 모델별로 상이               |

(참고: The Verge, 2026-07-04)

## 구매 전 반드시 체크할 5가지

1. **숫자 입력 빈도**  
   숫자 입력이 잦은 업무(회계, 데이터 입력 등)에 적합합니다.

2. **키맵핑/매크로 활용도**  
   커스텀 키맵, 매크로를 적극 활용한다면 VIA 지원이 강점입니다.

3. **디자인 취향**  
   CRT 스타일 레트로 디자인에 호감이 있는지 고려하세요.

4. **CRT 화면 필요 여부**  
   키 설정을 자주 바꾼다면 실용적이지만, 그렇지 않다면 단순화된 모델이 더 나을 수 있습니다.

5. **예상 가격대**  
   공식 가격은 미공개이나, 브랜드 특성상 10만 원대 중후반 이상이 예상됩니다.

## 주의할 점

RT98은 숫자 키패드를 중시하는 사용자들의 오랜 불만을 해결한 제품이지만, 모든 사용자에게 완벽한 선택은 아닐 수 있습니다. CRT 스타일 화면과 다양한 기능이 오히려 불필요하게 느껴질 수 있으니, 실제 사용 환경에 맞는지 점검이 필요합니다.

Epomaker RT98은 2026년 7월 4일 공식 공개 기준으로 발표됐습니다. 상세한 가격, 국내 공식 판매 여부, 구매처 등은 Epomaker 공식 홈페이지와 국내 총판 공지를 참고하세요.
