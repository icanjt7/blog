## 주요 이슈: LG 모니터의 McAfee 팝업 광고 중단

2026년 7월 24일, Microsoft는 Windows 11 사용자들이 LG 모니터에서 반복적으로 McAfee 체험판 팝업 광고를 겪는 문제를 해결하기 위해 직접 개입했습니다. LG는 Microsoft의 요청에 따라 해당 광고 소프트웨어를 즉시 비활성화하기로 결정했습니다.

## 배경 설명

- **LG전자**: 글로벌 전자제품 제조업체로, 모니터 및 다양한 IT 기기를 생산합니다.
- **Microsoft**: Windows 운영체제를 개발·운영하는 세계적인 소프트웨어 기업입니다.
- **McAfee**: 미국의 대표적인 보안 소프트웨어 브랜드로, 주로 바이러스 백신 솔루션을 제공합니다.

최근 LG 모니터를 사용하는 Windows 11 사용자들은 McAfee 체험판 설치를 유도하는 팝업이 반복적으로 나타나 불편을 겪었습니다. 이 문제는 운영체제와 모니터 제조사, 그리고 보안 소프트웨어 간의 협업 구조에서 발생한 것으로, 사용자 불만이 커지자 Microsoft가 직접 조치를 취했습니다.

## 꼭 알아둘 포인트

- **실제 영향**: 기존에 지속적으로 나타나던 McAfee 광고 팝업이 사라져, 모니터 사용 환경이 개선됩니다.
- **적용 범위**: Windows 11이 설치된 LG 모니터에만 해당됩니다.
- **비용 변화 없음**: 광고 팝업 중단만 해당되며 별도의 요금 변화는 없습니다.
- **향후 안내**: 추가적인 소프트웨어 변경이나 업데이트는 Microsoft와 LG 공식 채널을 통해 확인 가능합니다.
