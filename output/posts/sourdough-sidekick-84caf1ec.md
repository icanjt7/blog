## Sourdough Sidekick란?

Sourdough Sidekick는 미국의 제빵 재료 기업 King Arthur Flour에서 공식 지원하는 발효 스타터 자동 관리 기기입니다.  
King Arthur Flour는 200년 역사의 밀가루 및 발효 전문 브랜드로, 품질과 교육에서 높은 신뢰를 얻고 있습니다.

사워도우(Sourdough) 빵은 자연 발효로 만들어지며, 효모와 박테리아가 밀가루 속에서 성장합니다.  
이 과정에서 스타터(효모덩어리)를 매일 관리해야 하지만, 반복되는 물·밀가루 투입과 환경 조절은 시간과 노력이 많이 듭니다.

## 자동화의 실제 작동 방식

Sourdough Sidekick는  
- 스타터 용기를 자동 감지  
- 물과 밀가루 투입 자동화  
- 온도, 습도 센서로 발효 환경 일정 유지  
- 앱 연동을 통한 상태 모니터링  
- 관리 알림 제공  
등의 기능을 갖췄습니다.

특히 King Arthur Flour 시범 베이커들은 “빵 굽기에 집중할 수 있다”, “최대 6시간 관리 시간을 절약했다”는 평가를 내놓았습니다.

## 직접 관리 vs Sourdough Sidekick 비교

|---------------------|-------------------|--------------------------------------|
| 물·밀가루 투입      | 수동, 매번 필요   | 자동 투입, 시각 알림                |
| 온도·습도 관리      | 수동 측정         | 센서로 자동 감지                     |
| 스타터 상태 확인    | 직접 눈으로       | 앱 데이터로 실시간 확인             |
| 일일 관리 시간      | 1~2시간           | 10~20분                              |
| 스타터 용기 호환    | 대부분 가능       | 일부 용기에 한정, 호환 체크 필요     |
| 오작동 시 대응      | 즉시 수동 가능    | 앱 알림 후 수동 확인 필요            |

## 실제 사용 시 주의사항

자동화가 모든 문제를 해결하지는 않습니다.  
스타터 상태가 예상과 다를 때는 직접 눈으로 확인하는 습관이 필요합니다.  
초기 앱 설정과 용기 호환 체크를 반드시 해야 하며, 완전 자동화보단 ‘반자동 관리’에 가까운 점을 기억하세요.
