## 자율주행차 안전 기준, 왜 논란인가?

Waymo(Alphabet 계열 자율주행 기업)는 실제 도로에서 모든 사고 상황을 시험할 수 없기에 시뮬레이션이 필수적입니다.  
이때 사용되는 Reference Driver(인간 운전자 모델)는 완벽한 운전자가 아니라, 실제 인간의 인지 속도와 반응 지연, 놀람 행동 등을 반영해 자율주행차와 현실적 비교가 가능하도록 설계됐습니다.

### 기술적 맥락  
- 자율주행 시뮬레이션에서 인간 운전자 모델이 반드시 필요  
- 단순 주행거리나 무사고 기록만으로 안전성을 평가하기 어렵기 때문  
- Reference Driver는 위험 상황에서 인간이 보일 법한 반응을 수치로 구현

## 독자가 기억할 세 가지

- Reference Driver는 Waymo 차량의 직접 운전 기능이 아니라, 인간 운전자와의 비교를 위한 기준 모델이다.
- 자율주행차의 안전성은 단순 사고 건수나 총 주행거리만으로 판단할 수 없으며, 상황별 인간 반응과 비교가 필수적이다.
